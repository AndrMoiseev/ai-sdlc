# Поведенческая проверка sdd-apply: сценарий 7

**Итог: 3/3 ожидания узкой проверки обработки находок подтверждены независимым оценщиком.**

| Ожидание | Результат |
| --- | --- |
| Каждый блокер имеет принятый источник и конкретное нарушение | Подтверждено: DEC-validation и AGENTS.md |
| Архитектурные и проектные нарушения исправляются при зелёных тестах | Подтверждено: helper и __all__ |
| Предпочтение имени откладывается без автоматической правки | Подтверждено: add сохранён, рекомендация записана |

Исходный рабочий код с зелёными утверждениями нарушал принятую архитектуру и проектное правило. Оба нарушения исправлены. При проверке найден и исправлен дополнительный OverflowError для больших конечных целых. Предпочтение переименовать add не стало основанием изменения API.

Это запуск от свежего согласованного плана с предоставленными синтетическими находками, а не возобновление прежнего review-состояния. Источники, команды, Git и сохранённый runtime подтверждают три узких ожидания. Первичные spawn/send отсутствуют в ephemeral JSONL; полная независимость заявленных ролей не доказана.

Контрольные варианты отсутствуют, сравнительное улучшение не утверждается. Время прямого запуска записано как верхняя граница в timing.json; метрики сохранены. Ограничение времени снято пользователем.
