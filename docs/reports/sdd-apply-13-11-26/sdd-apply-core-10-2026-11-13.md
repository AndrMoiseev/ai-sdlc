Подготовка создала настоящий UU-конфликт с prepared intent и apply_started:true. Свежая измеряемая сессия использовала тот же intent, зарегистрировала resolver, сохранила внешнее исправление и задачу, завершила через worktree_refresh_resolve и довела план до приёмки. Локальный интеграционный коммит c0d25df.

Вывод подтверждён первичными native-запусками, завершениями дочерних контекстов, Git и runtime-свидетельствами. Текст части dispatch-сообщений зашифрован; малый синтетический проект и эта телеметрия ограничивают более широкие выводы. Контрольных вариантов нет; сравнительное улучшение не утверждается.

Полные доступные host traces подготовки, измеренного запуска и отдельного оценщика, runtime store и Git bundle сохранены. Код завершения 0, wall time и метрики записаны. Пользователь снял ограничение времени.
