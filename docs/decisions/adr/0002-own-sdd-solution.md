# ADR-0002: Собственное решение для SDD-процесса

По итогам [исследования OpenSpec](../research/0002-openspec-customization-vs-own-implementation.md) выбираем разработку собственного решения для наших команд и проектов. Сохраняем полезные идеи OpenSpec и базовый набор документов, но не делаем его обязательной технической зависимостью.

Требуемый процесс включает собственные правила трассировки, архитектурные линзы, независимые агентские ревью и решения пользователя. Большую часть этой логики пришлось бы реализовать и в надстройке над OpenSpec. Дополнительная польза его механизмов по сравнению со стоимостью адаптации и сопровождения совместимости пока не очевидна и не доказана. Это не доказывает, что собственное решение будет дешевле: ответственность за его реализацию, синхронизацию документов и сопровождение принимаем на себя.

Решение может быть пересмотрено в процессе реализации, если выявятся дополнительные преимущества OpenSpec или существенные недостатки собственного подхода. Основанием для пересмотра должны служить конкретные результаты реализации и сравнения, а не необходимость сохранять первоначальный выбор.
