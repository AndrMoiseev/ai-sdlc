# Адаптер произвольного агента

Выполняй задачу по доступным материалам и подтверждённым возможностям среды. Не предполагай специальные команды вызова, каталог скиллов, доступ к файлам, запись, запуск программ или субагентов. Если чтение файлов недоступно, запроси исходные материалы. Если запись недоступна, выдай текст глоссария с предполагаемым путём и отметь, что файл не сохранён.

Для редактуры опиши задания редактору и проверяющему прозой по [контракту прохода](editorial-pass.md): цель, материалы, защищённые фрагменты, допустимые изменения и ожидаемый отчёт. Для каждого нужен подтверждённый отдельный свежий контекст без истории автора; проверяющий не получает исходник и выводы редактора. Названия инструментов и параметры Codex или Claude Code здесь не предполагаются.

Если humanizer-ru или независимые контексты недоступны, результат остаётся черновиком с указанной причиной незавершённой редактуры. Саморедактура не закрывает этот этап. Для недоступного линтера применяй только ручную проверку, предусмотренную humanizer-ru, и укажи способ проверки. Сообщай отдельно, что подготовлено, сохранено и фактически проверено.
