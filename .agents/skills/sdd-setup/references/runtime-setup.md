# Условия запуска

Определи путь этого скилла из загруженного SKILL.md и прочитай
[общие условия запуска](../../sdd-shared/references/runtime-setup.md).
Нужны `scripts/setup.py`, соседний lock-файл и полный пакет `sdd-shared` рядом
со скиллом. При другом расположении передай `--sdd-shared <shared-root>`;
прежний `--sdd-spec` указывает на соседний с ним sdd-shared.

```text
uv run --locked --script "<skill-root>/scripts/setup.py" --help
```

Храни inspection/request/plan, каталоги хоста и отчёты в отдельном рабочем
каталоге вне исходных и установленных коллекций скиллов и вне настраиваемого
проекта. Они могут содержать исходное содержимое определений агентов. Сохраняй
план до окончания проверки: он содержит исходные тексты и diff для восстановления.
Скрипты отключают bytecode; тестовый runner отключает pytest cache.

Используй достоверную текущую среду, а не наличие `.codex` или `.claude` в проекте.
Для Claude Code сначала сохрани JSON-массив имён из действительного каталога
Agent tool/хоста; наличие файлов не заменяет каталог. Если каталог недоступен,
сообщи, что проверка существующих агентов заблокирована, и продолжай обсуждать
пресеты без записи. В Codex скрипт читает проектные TOML и пользовательский
каталог из `CODEX_HOME` либо стандартного `~/.codex/agents`.

Выбирай исходный корень проекта. Если идёт `sdd-apply`, изменение настроек может
сделать снимки исходников устаревшими; выполняй настройку между задачами либо
пройди штатное согласование нового снимка перед продолжением. Вызов setup не
перенастраивает уже работающих субагентов.
