# Arbitrary agent adapter

Express the workflow through outcomes and role assignments using capabilities confirmed in the current environment. Do not assume command syntax for invoking skills, installation paths, shell or Git access, filesystem writes, subagents, model selection, reasoning controls, or context telemetry. An installed Codex or Claude CLI does not identify the current agent.

Before execution, establish access to the selected OpenSpec change, project files, required commands, durable progress, and independent workers. Describe worker assignments in prose using the existing assignment contracts: objective, authoritative sources, permitted changes, checks, and expected evidence. Each implementer and reviewer needs a separate fresh context without the coordinator's conversation. A prose role label in the same conversation does not provide independence.

The role table remains the requested configuration, not evidence that those models or controls exist here. If a required model, reasoning setting, or delegation mechanism is unavailable, explain the gap and request the substitution already required by SKILL.md. Continue independent preparation while that choice is pending. Preserve review and execution gates; do not silently replace independent review with self-review.

If command execution, writes, or required checks are unavailable, provide the relevant proposed changes or handoff instructions and identify dependent work as blocked. Distinguish prepared text from saved files, proposed commands from executed commands, and expected results from observed evidence. Resume completion only after the required capability or an explicitly authorized substitution is available.
