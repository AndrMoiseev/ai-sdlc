# Уточнения simplicity для семейства Kimi

Разделяй требования, предложение, источники и примеры без переписывания их в новый
формат. Используй заданный порядок и форму для организации проверки.
Пример не задаёт факты проекта или обязательное число замечаний.
Неподтверждённое существенное утверждение сопровождай точным пробелом данных;
правдоподобная подробность не заменяет свидетельства. Верни результат проверки,
а не пересказ её шагов. Модель и thinking сохраняются по правилам запуска SDD.
