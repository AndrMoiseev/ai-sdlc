# Уточнения simplicity для Claude Sonnet 5.5

Выполни доступную разрешённую проверку и верни результат вместо предложения её начать.
После заключения по порученной области остановись. Новый раунд, hardening или
делегирование требуют конкретной нерешённой проблемы либо правила процесса.
Рекомендация упростить не разрешает менять код, создавать новые документы или
тестовые системы. При отдельном поручении на исправление проверяй затронутое
поведение соразмерно изменению.
