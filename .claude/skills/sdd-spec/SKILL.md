# SDD Spec

## Начало

Запускай только по явному `$sdd-spec`, `/sdd-spec` или выбору пользователем этого скилла. Последующие сообщения продолжают выбранный процесс без повторного вызова. В новой сессии обычная просьба спланировать изменение не активирует sdd.

Перед работой прочитай [условия запуска](references/runtime-setup.md), [формат документов](references/document-format.md) и адаптер среды: [Codex](references/codex.md), [Claude Code](references/claude-code.md) или [произвольный агент](references/generic.md), если ни одна из этих сред не установлена достоверно. Выбери изменение и проверь сохраненные основания через [resume](flows/resume.md), затем открой нужный флоу.

## Выбор флоу

Для исследования, черновика, пересмотра и продолжения прочитай
[правила обсуждения](references/discussion.md): существенные решения принимает
пользователь; черновик сохраняй с предложениями, журналом авторства и открытыми
вопросами. После сохранения продолжай обсуждение ближайшего выбора.

После завершённой порции правок документов, включая черновики, предложи
[гуманизацию через humanizer-ru](references/editorial-pass.md). Запускай её только
по явному согласию пользователя в указанной области. Отказ или отсутствие ответа
не блокируют основной процесс; при продолжении учитывай сохранённый выбор.

| Намерение и проверенное состояние | Флоу |
|---|---|
| Исследовать идею, уточнить пробел или блокирующий выбор | [explore](flows/explore.md) |
| Подготовить proposal, specs и обязательный design | [draft](flows/draft.md) |
| Пересмотреть существующие документы | [revise](flows/revise.md) |
| Подготовить или обновить пояснение решения, продолжить превью | [explain](flows/explain.md) |
| Запустить согласованное независимое ревью | [review](flows/review.md) |
| Рассмотреть находки, исключения и согласования | [user-review](flows/user-review.md) |
| Создать план по явной команде или согласовать готовый | [plan](flows/plan.md) |
| Продолжить после перерыва или восстановить checkpoint | [resume](flows/resume.md) |

Сохраняй документы в `sdd/changes/<change-id>/`. Результат процесса — согласованный план. Не реализуй код, не синхронизируй baseline и не запускай apply/archive. Просьбу о реализации отдели от этого процесса; сообщи его границу и состояние.

Примеры: «`$sdd-spec` поясни решение order-export с диаграммами»;
«`/sdd-spec` обнови пояснение order-export»; после начала процесса:
«Продолжи незавершённые превью по сохранённому промпту».

Происхождение и лицензия адаптированных инструкций: [OpenSpec](references/openspec-origin.md). Подключение полного пакета: [README](README.md). Проверочные процедуры: [manual](evals/manual.md).
