# Подготовка инструкции simplicity

Сначала выбери субагента по [общим правилам SDD](../../sdd-shared/references/subagents.md).
Для каждой линзы документов используется `sdd-spec.document_reviewer`, для обеих
линз плана — `sdd-spec.plan_reviewer`; контексты остаются отдельными.
Этот документ и модельные дополнения не меняют модель, reasoning, инструменты,
полномочия, consent, независимость или формат отчёта.

После выбора подготовь текст для simplicity через установленный пакет:

```text
uv run --python "<python>" --locked --script "<skill-root>/scripts/simplicity.py" --model "<model-id>"
```

Применяй [runtime](runtime-setup.md). Передавай достоверный ID из наблюдения хоста
либо точный запрошенный ID из результата resolver. Наблюдение фактической модели
имеет приоритет. Если известен только запрос, сохрани это различие в существующих
данных запуска: поле model в ответе селектора повторяет вход, а не доказывает
фактическую модель. Имя роли, слова агента и модель родителя при назначенной другой
модели не заменяют ID. При неизвестном ID опусти `--model`.

Селектор возвращает общую линзу и ровно одно дополнение: точное модельное,
иначе семейное для распознанного ID, иначе только общую линзу. Таблица соответствий
живёт в скрипте; агент не угадывает ближайшую модель и не читает все дополнения.
Передай рецензенту полностью `instructions`, stage и обычный пакет поручения;
`profile` сохрани рядом с данными выбора субагента. Если хост сообщил подмену,
подготовь инструкцию для наблюдаемого ID до содержательного ревью. При невозможности
установить ID используй общие критерии и укажи ограничение.

Неизвестная модель или отсутствие специального дополнения не блокирует ревью.
Ошибка чтения выбранного файла означает повреждённый пакет: восстанови его или
зафиксируй incomplete для зависимой проверки, без выдуманного успешного результата.
Селектор не читает конфигурации среды, журналы сессий и чужие потоки, не запускает
субагентов и ничего не записывает.

Предметные гарантии одинаковы для всех моделей. Дополнения уточняют способ работы;
при противоречии действуют инструкции SDD и пользователя.
