# Диалог

Используй текущие значения и пресеты из `inspect.summary`; файл
[defaults.json](../assets/defaults.json) читает скрипт. Имена пресетов общие для
сред, модель/effort зависят от роли и среды. Пресеты рекомендуют выбор,
но не подтверждают доступность модели в аккаунте.

## Роли

Покажи таблицу «роль / текущее имя / предлагаемое имя / модель и effort».
Для отсутствующих ролей предлагай `default`; для существующих — оставить текущее
имя. Предложи «принять показанные значения / изменить выбранные». Длинный диалог
разбей на группы: проверка спецификаций, редактирование, исполнение, проверка кода.
Не заменяй эту таблицу вопросом «какие настройки хотите?».

Покажи `sdd-spec.explorer` и `sdd-apply.explorer` отдельно. Их общий пресет
`sdd-explorer` наследует модель и effort; при принятии создай одно определение.
Пользователь может выбрать для этих ролей разные профили.

Пользователь может выбрать имя существующего агента, новое имя или наследование
родительской модели без именованного агента. Последнее сохраняется отсутствием
ключа роли; в request это явное `set` со значением `null`. Это не значение по
умолчанию. Служебный `schema_version: 1` пользователь не выбирает.

Если пользователь выбрал новое имя, выполни `inspect --names <name> --output <new-file>`
с теми же корнем, средой и дополнительными именами. Сохрани ответы, обнови
ссылку/хэш снимка и учти
найденное определение. Отсутствие агента не повод спрашивать отдельное разрешение
на его создание: создание входит в настройку выбранного имени.

## Модель и effort

Для каждого уникального выбранного имени покажи:

- связанные роли и область существующего определения;
- текущее значение каждого поля, либо «не задано»;
- конкретный пресет модели и effort для этой роли в текущей среде;
- выбор «оставить» для заданного значения, «принять пресет» или «указать другое».

Когда оба поля не заданы, нельзя молча сохранить наследование. Предложи пресет;
наследование можно выбрать явно. Для модели `null` означает наследование, для
effort — удалить явное значение и использовать поведение хоста. У Codex при смене
модели без effort SDD использует effort новой модели по умолчанию; у Claude
удалённый effort оставляет настройки сессии/хоста.

Для explorer наследование уже является пресетом: покажи его явно, и принятие
пресета считается выбором наследования. При повторной настройке сохраняй такой
выбор явным `set: null` для незаданных полей; `keep` незаданного поля по-прежнему
не заменяет решения пользователя.

Если роли одного имени имеют разные пресеты, перечисли эти варианты и предложи
выбрать одну пару либо разделить роли по именам. Скрипт отвергает неоднозначный
`default`. При одинаковом пресете настраивай агент один раз.

Для агента, видимого только в нативном каталоге Claude Code, значения модели и
effort могут быть неизвестны. Покажи «управляется средой, значение недоступно»,
предложи сохранить определение либо выбрать новое проектное имя для настройки.
Не выдавай пресет за текущее значение. Для доступного пользовательского файла
изменение создаёт проектную копию; покажи это в плане.

Предлагай модели из возможностей текущего хоста, если он раскрывает их список.
Если модель пресета заведомо недоступна, покажи этот факт и предложи доступную
замену. Если список недоступен, обозначь непроверенную доступность, сохрани
явный выбор пользователя и не выдумывай подтверждение запуска. Скрипт не делает
запросов к моделям. Вопрос о совместимости не разрешается тихим fallback на родителя.

## Запись

Зафиксируй ответ для каждой строки. «Принять всё показанное» достаточно; молчание
или истёкший таймер ответом не считаются. Если предпочтение уже было дано в этой
сессии, используй его без повторного вопроса.

Покажи краткий план: какие роли изменятся, какие агенты создаются/обновляются,
их модели и effort, конкретные пути. `plan.summary.operations[].diff` даёт точный diff.
Если все решения уже приняты, выполни `apply`. При отмене до записи оставь проект
без изменений. Повторный вызов с сохранением всех текущих значений не переписывает
файлы. Форматирование JSON сохраняется при отсутствии смысловых изменений;
при изменении JSON переформатируется с сохранением неизвестных верхних полей.
