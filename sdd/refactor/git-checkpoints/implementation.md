# Выполнение плана Git-чекпойнтов

Дата: 2026-10-27. Основание: [plan.md](plan.md), [decisions.md](decisions.md).
Исходная точка реализации: `5c9fe3d63d6ebadab8a45d89f800101ef7662ff9`.

## Организация

Каждая из шести задач назначена отдельному субагенту: `task1_contract`,
`task2_git`, `task3_format`, `task4_instructions`, `task5_consumers`,
`task6_tests`. Исходные наборы проверил `baseline_tests`; независимое ревью
провёл `independent_review`. Основной агент координирует изменения и коммиты.
Автоматические поведенческие эвалы и модельные тесты не запускались.

## Реализация

- Общий контракт описан в [contract.md](contract.md).
- Добавлены inspect/accept/create Git-чекпойнтов, наблюдение проверенного дерева,
  контроль HEAD/ref, compare-and-swap и диагностика частичных сбоев.
- Общий API переведён на v2; изменённые state/review/USER-форматы используют
  commit references. Нормативные документы сохраняют схему v1.
- Инструкции sdd-spec используют чистый вход, проверенный переход и отдельное
  принятие состояния. Исторические хэши документов больше не служат запретом
  продолжения. Принятие состояния не расширяет поручение.
- Потребители sdd-apply/setup/sync согласованы с API v2. В apply сохраняются
  коммит и разобранные записи принятого плана; отдельная целостность исходников,
  кандидатов, проверок и transfer-пакетов сохранена.

## Независимое ревью

Рецензент проверил итоговые изменения относительно исходной точки без правок
и без запуска тестов. Найденные проблемы исправлены и повторно проверены:

1. Возобновление apply могло принять грязное дерево или неизвестный HEAD.
   Добавлены контроль известного коммита исполнения и явное принятие внешнего
   коммита. Создание worktree, интеграция и refresh не обходят эту проверку.
2. Git status мог скрывать правки при assume-unchanged/skip-worktree.
   Такие флаги теперь диагностируются; файлы, флаги и ссылки сохраняются.
3. Тестовый адаптер автоматически принимал новый HEAD. Фикстура теперь хранит
   явную принятую точку, а отдельная регрессия проверяет дополнительный коммит.

Итог повторного ревью: подтверждённых открытых блокирующих замечаний нет.
Дополнительная проверка оптимизированных фикстур также не выявила замечаний:
разобранное основание глубоко копируется, идентичность worktree проверяется
реальным Git, повторно используемое основание сравнивается со свежей валидацией.
Итоговые автотесты завершены успешно; все шесть задач выполнены.

запускает процесс скрыто, контролирует код выхода и завершает дерево процессов
