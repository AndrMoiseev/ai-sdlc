# Пояснение решения с диаграммами archify

## Проблема и результат

После подготовки proposal, specs и design пользователь получает формальное
описание изменения. Чтобы оценить решение, ему приходится самостоятельно
сопоставлять модули, процессы и сценарии и выяснять, какие части сохраняются.

sdd-spec будет предлагать отдельное пояснение с диаграммами archify после
подготовки черновика. Пользователь увидит изменения в контексте существующей
системы. Превью в документе будут ссылаться на интерактивные HTML-диаграммы.
В среде без браузера агент оставит видимые заглушки и подготовит промпт для
завершения проверки и вставки превью в другой среде.

## Объём

Новая capability [solution-explanation](specs/solution-explanation/spec.md):

- предложение пояснения после черновика и создание по выбору пользователя;
- один документ или связанный набор документов с архитектурными диаграммами,
  диаграммами процессов и диаграммами последовательностей;
- единые обозначения добавленных, изменённых и неизменённых элементов;
- получение превью при проверке archify, обработка недоступного браузера
  и продолжение работы по сохранённым артефактам;
- хранение артефактов внутри изменения и проверка их актуальности при пересмотре.

Изменение затрагивает инструкции, шаблоны, документацию подключения и сценарии
проверки поведения sdd-spec. Конкретные точки подключения описаны в
[design](design.md).

## Исключения

archify сохраняется без изменений. Генерация пояснения необязательна для
согласования основного комплекта документов. Изменение не добавляет новый
нормативный тип документа, не меняет формат sdd v1 и условия разрешения ревью
или планирования. Встроенные check и snapshot сохраняют нынешнюю область.

Пояснение описывает предлагаемое решение; его подготовка не реализует код
продукта. Автоматическая установка зависимостей, публикация HTML и отдельный
сервис генерации изображений в объём не входят.

## Влияние

В каталоге изменения появятся необязательные explanation.md, при необходимости
explanation/ и каталог archify/. Существующие изменения продолжат работать
без этих файлов. Пояснения будут ссылаться на требования и решения основного
комплекта. Только правки этого комплекта влияют на его манифест и согласование.

Зависимость archify уже объявлена в packages/common-dependencies/apm.yml.
При ручном подключении sdd-spec пользователю потребуется установить archify
отдельно для генерации диаграмм. Недоступность этой зависимости будет сообщаться
как ограничение пояснения.
