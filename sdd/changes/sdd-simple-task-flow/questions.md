# Вопросы изменения

Все три вопроса показаны пользователю в текущем чате. Ответов или поручения решить этот список пока нет. Просьба сохранить результаты не является выбором вариантов.

### Степень упрощения

```yaml
sdd_record: question
id: Q-preparation-depth
text: Какую степень упрощения выбрать для подготовки простой задачи?
blocking: true
status: open
```

Варианты: компактный контракт с общим исполнением; автоматическая подготовка полного комплекта.
Рекомендация: компактный контракт. Он сокращает подготовку, но требует изменения входа и форматов. Полный комплект сохраняет больше текущей механики и её накладных расходов.
Выбор определит объём подготовки и основу будущего дизайна.
Источник: [предложение и его авторство](decisions.md#степень-упрощения).

### Допустимые задачи

```yaml
sdd_record: question
id: Q-task-scope
text: Допускать ли в простой флоу ограниченное новое поведение наряду с исправлениями?
blocking: true
status: open
```

Варианты: исправления и ограниченные новые функции; только исправления под действующие требования.
Рекомендация: оба вида при однозначном результате и проверяемых критериях. Для нового поведения нужно сохранить изменение требований для последующего sync. Ограничение исправлениями уменьшает эту работу, но сужает пользу флоу.
Выбор определит границы маршрута, критерии допуска и взаимодействие с sync.
Источник: [предложение и его авторство](decisions.md#допустимые-задачи).

### Подтверждение запуска

```yaml
sdd_record: question
id: Q-start-authorization
text: Достаточно ли исходного явного поручения выполнить задачу без повторного подтверждения контракта?
blocking: true
status: open
```

Варианты: исходного поручения достаточно, если контракт точно ему соответствует и существенных вопросов нет; перед каждым выполнением необходимо отдельное подтверждение компактного контракта.
Рекомендация: достаточно исходного поручения. Альтернатива даёт дополнительный контроль ценой обязательной паузы.
Выбор определит будущие правила согласования, Git-входа, start и resume; он не даёт разрешения на текущую реализацию.
Источник: [предложение и его авторство](decisions.md#подтверждение-запуска).
