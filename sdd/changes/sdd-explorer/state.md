## Runtime

Для read-only скриптов выбраны `UV_CACHE_DIR` и `UV_TOOL_DIR` в системном временном `uv-runtime`; системный Python найден через uv: Python 3.14. `PYTHONDONTWRITEBYTECODE=1` задаётся в каждом процессе. Проверка Python записи в созданный им временный каталог получила PermissionError; неизменённый probe не повторялся. Для команд, которым нужен такой доступ, применять штатное расширение доступа к конкретной команде по AGENTS.md. Структурный checker сам проект не изменяет.
