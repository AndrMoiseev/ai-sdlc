## Незакоммиченные изменения и файловый просмотр панели

Также не очень понял принип работы с HTML-панелью, я бы ожидал что HTML сам будет по таймеру перечитывать актуальное состояние и обновлять элементы.

> Хорошо, мы же можем сделать генерацию dasbord-state.js с помощью скрипта? По поводу worktree я не понял зачем нам хранить коммиты. Я видел это так: независимые агенты работают в worktree без коммитов, после готовности задачи оркестратор переносит изменения из worktree в основную ветку и делает коммит, после чего удаляет worktree. Коммит сохраняется в рабочей ветке.

Выбраны worktrees в detached HEAD, без веток задач и коммитов исполнителей.
Оркестратор сохраняет пакет незакоммиченных изменений, переносит его
в рабочую ветку исполнения и организует независимые проверки интеграции.
После успешных проверок и ревью создаёт коммит, записывает приёмку
и удаляет worktree, проверив отсутствие новых неучтённых данных.
Прерванный перенос восстанавливается по пакету, состоянию файлов и истории
рабочей ветки без повторного применения и дублирования коммита.

Каноническое имя файла панели: `dashboard-state.js`. Скрипт генерирует его
из `state.json`; HTML открывается с диска и по таймеру обновляет элементы.
