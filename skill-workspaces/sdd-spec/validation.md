## Автоматические проверки

```text
uv run --project skills/sdd --locked python -m pytest skills/sdd/tests -q
openspec validate sdd-skill-planning-pilot --strict
```

Результат: **127 passed, 1 skipped**. Пропущена проверка создания symlink: в Windows отсутствует соответствующая привилегия. Проверены нормализация путей, выход за назначенный корень, безопасный YAML, ID/ссылки, операции требований, покрытие/граф задач, verification, манифесты, линзы, история отчетов, области USER-решений, отмена/замена, восстановление state и публичные команды из другого рабочего каталога с пробелами. Заполненные поставляемые шаблоны проверены вместе на двух capabilities.

OpenSpec strict validation проходит. Системные ограничения среды потребовали разрешенного запуска pytest за пределами sandbox: созданные pytest временные каталоги были недоступны в sandbox. Это ограничение окружения, не пропущенный набор тестов. Зависимости закреплены в uv.lock; uv 0.12.5, тестовый Python 3.14.

## Skill Conductor

[Структурные результаты](structural.json): 14/17 пунктов, все критические проходят. Три некритических предупреждения сохранены без подмены на pass:

- README внутри пакета прямо требуется планом пользователя.
- Положительные и отрицательные фразы автоматического triggering не добавлены: sdd запускается только явно, описание предназначено пользователю.

На Windows проверка conductor выполнялась с `PYTHONUTF8=1`; без этого его read_text использует системную cp1251 и не читает русский Markdown. Автоматическое discovery и оптимизация description пропущены по правилу explicit-only, не объявляются успешными проверками.

[Первичный baseline](baseline/response.md) выявил несоответствие специфическому формату sdd без навыка. [Сравнительный HTML-отчет](iteration-1/review.html), [benchmark](iteration-1/benchmark.json) и [анализ](iteration-1/analysis-notes.json) содержат 14 завершенных чистых запусков Codex CLI: пять повторов сценария давления на пропуск ревью для каждого варианта и по одной паре создания плана/продолжения отмененного поручения. Все процессы сохранили read-only sandbox; исключены три ранних native-прогона, после которых среда перестала освобождать слоты субагентов. Внешняя инициализация CLI потребовала разрешенного запуска, дочерние разрешения не расширялись.

Со скиллом выполнены **29/29** бинарных условий, без него — **25/29**. Различие получено в единственной паре создания плана: две задачи со смысловыми ID и единственным владельцем AC проходят независимую [проверку структуры](iteration-1/artifact-validation.json); контрольный план использует числовые ID, не задает машинные записи/verification и повторно назначает AC отдельной проверочной задаче. Пять повторов давления дали B в обоих вариантах, без наблюдаемого разброса выбора; отмененное поручение также не возобновляется обоими вариантами. Эти два сценария насыщены правильными ответами и не доказывают преимущество скилла.

Сценарии с давлением/отменой задают факты в prompt и проверяют заявленный следующий шаг, а не восстановление реальных файлов. Проверка формата плана имеет одну пару, поэтому общая надежность из нее не выводится. Время и токены CLI сохранены как измеренные/сообщенные; скилл требует больше ресурсов, часть трасс содержит повторные чтения русских файлов из-за Windows-кодировок. Их точный вклад в разницу не оценивался. Автоматическая регистрация команды в клиенте и runtime Claude Code этими опытами не подтверждаются.

[Проверка неизменности](iteration-1/candidate-integrity.json): все 53 исходных файла совпадают с замороженной копией. Пакет после этих ответов не редактировался; отчет показан пользователю до возможной следующей итерации.

## Независимый аудит

[Отчет](code-review.md): три подтвержденные ошибки исправлены и покрыты регрессионными тестами. История планового ревью OpenSpec сохранена; обновление чекбоксов tasks меняет его байтовую версию, поэтому прежнее ревью плана не объявляется актуальным для новой версии.

Рекомендации планового ревью учтены в реализации: проверка отмены/замены поручения присутствует в тестах и manual, общий manual.md написал один исполнитель. Это сведения о реализации, а не выдуманные ответы пользователя по находкам.

## Границы подтверждения

Codex CLI 0.159.0 технически сверен со справкой и официальной документацией; политика явного вызова проверена статически. Claude Code отсутствует в PATH, его адаптер проверен по документации. Минимальная испытанная версия Claude Code не установлена. Реальные сквозные прогоны в обеих средах и выбор проекта для пилота находятся за пределами изменения. Записи согласований не являются доказательством авторства пользователя; скрипты не оценивают семантическую полноту требований и тестов.
