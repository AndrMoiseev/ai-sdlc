# Дизайн

## Контекст
[Объем](proposal.md), [требования](specs/main/spec.md).

## Модули и контракты
Планировщик запускает сборку CSV из хранилища доставок; диспетчер получает файл через существующий канал до назначения исполнителей в 07:30. Назначение остаётся ручным.

Точный срок доступности файла и зависимое расписание сборки остаются открытыми: [Q-report-time](state.md#время-отчёта). Прежние 08:00 не применяются.
