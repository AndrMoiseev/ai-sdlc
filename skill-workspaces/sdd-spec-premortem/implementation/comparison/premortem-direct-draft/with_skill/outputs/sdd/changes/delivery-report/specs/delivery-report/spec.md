# Отчёт о просроченных доставках

Черновик подтверждённой части контракта по [источнику](../../../../../docs/report.md). Незаданные правила не считаются согласованными. Вопросы находятся в [state.md](../../state.md).

## Ежедневный отчёт для диспетчера

```yaml
sdd_record: requirement
id: REQ-daily-report
operation: add
```

Диспетчер доставки должен получать отчёт о просроченных доставках ежедневно в 09:00. Часовой пояс и канал получения пока не определены; часовой пояс среды не является требованием продукта.

### Расписание и получатель

```yaml
sdd_record: acceptance
id: AC-daily-recipient
requirement: REQ-daily-report
conditions: Наступило 09:00 очередного дня в согласованном часовом поясе; данные доступны и канал передачи согласован.
expected: Диспетчеру доставки предоставлен ежедневный отчёт о просроченных доставках.
```

Критерий условный: для исполнимой проверки требуется закрыть Q-report-contract. Допустимая задержка и поведение при сбое не заданы.

## Поля CSV

```yaml
sdd_record: requirement
id: REQ-csv-fields
operation: add
```

Отчёт должен иметь формат CSV с полями delivery_id, overdue_minutes, responsible. delivery_id обозначает доставку, overdue_minutes — её просрочку в минутах, responsible — ответственного. Правила идентификации ответственного, отбора доставок и вычисления значения просрочки остаются открытыми.

### Состав полей

```yaml
sdd_record: acceptance
id: AC-csv-fields
requirement: REQ-csv-fields
conditions: Сформирован CSV по согласованному набору просроченных доставок с известными значениями полей.
expected: CSV содержит поля delivery_id, overdue_minutes, responsible и соответствующие значения для включённых доставок.
```

Типы значений, округление, пустая выборка, отсутствие ответственного, недоступные данные и повторная отправка не определены источником. До решения Q-report-contract контракты этих случаев открыты.
