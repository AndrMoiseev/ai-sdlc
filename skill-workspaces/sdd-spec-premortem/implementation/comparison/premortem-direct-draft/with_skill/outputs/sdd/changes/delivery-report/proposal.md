# Ежедневный отчёт о просроченных доставках

Черновик: открытые вопросы в [state.md](state.md) не позволяют считать решение готовым к ревью.

## Проблема и результат

[docs/report.md](../../../docs/report.md) задаёт цель — снизить просрочки доставок. Предлагается ежедневно в 09:00 предоставлять диспетчеру доставки CSV о просроченных доставках и ответственных. Масштаб текущих просрочек, исходная метрика и целевое снижение не указаны.

Выпуск CSV — проверяемый результат функции. Снижение просрочек — ожидаемый эффект, который пока не обоснован действием получателя; см. [премортем](premortem.md).

## Объем

Новая capability [delivery-report](specs/delivery-report/spec.md): ежедневный отчёт с полями delivery_id, overdue_minutes, responsible для диспетчера доставки. Существующих спецификаций в доступных материалах нет.

## Исключения

Автоматическое переназначение доставок, эскалации, уведомления клиентам и интерфейс управления доставками не включены. План реализации и код не входят в текущее поручение.

## Влияние

Появляется CSV для диспетчера. Источник данных, канал передачи, часовой пояс, правила отбора и расчёта просрочки требуют уточнения. Решение получателя может изменить достаточный состав данных; такие изменения пока не приняты. Технические варианты описаны в [design.md](design.md).
