# Отчёт о просроченных доставках

Черновой контракт основан на [docs/report.md](../../../../../docs/report.md). Критерии ниже фиксируют известные обязательства. Пока открыты вопросы в [state.md](../../state.md), они недостаточны для реализации и полной приёмки.

## Ежедневное предоставление отчёта

```yaml
sdd_record: requirement
id: REQ-daily-report
operation: add
```

Отчёт должен ежедневно предоставляться диспетчеру доставки в 09:00. Часовой пояс и канал передачи не определены. Не установлено, означает ли 09:00 начало формирования или предельное время доступности; это требует уточнения Q-schedule-delivery.

### Расписание и получатель

```yaml
sdd_record: acceptance
id: AC-daily-recipient
requirement: REQ-daily-report
conditions: Наступил ежедневный срок 09:00 в согласованном часовом поясе; данные доступны и канал передачи согласован.
expected: Отчёт предоставлен диспетчеру доставки в соответствии с согласованным смыслом срока 09:00.
```

Критерий станет исполнимым после закрытия Q-schedule-delivery; параметры не выбраны автором.

## Содержание CSV

```yaml
sdd_record: requirement
id: REQ-overdue-csv
operation: add
```

Отчёт должен иметь формат CSV и поля delivery_id, overdue_minutes, responsible. Он показывает просроченные доставки, длительность просрочки в минутах и ответственного. Определение просрочки, момент среза, правила округления и идентификация ответственного пока неизвестны (Q-data-contract). Поведение при пустой выборке и ошибках также не определено (Q-report-failures).

### Поля отчёта

```yaml
sdd_record: acceptance
id: AC-csv-fields
requirement: REQ-overdue-csv
conditions: Сформирован отчёт по набору доставок с определёнными сроками и ответственными.
expected: CSV содержит поля delivery_id, overdue_minutes, responsible.
```

### Отбор и значения

```yaml
sdd_record: acceptance
id: AC-overdue-values
requirement: REQ-overdue-csv
conditions: Подготовлен контрольный набор с просроченными и непросроченными доставками по согласованным правилам Q-data-contract.
expected: Отчёт содержит просроченные доставки из контрольного набора с соответствующими идентификаторами, минутами просрочки и ответственными; непросроченные доставки исключены.
```

Конкретные контрольные значения появятся после определения правил данных; этот критерий пока не позволяет проверить расчёт.
