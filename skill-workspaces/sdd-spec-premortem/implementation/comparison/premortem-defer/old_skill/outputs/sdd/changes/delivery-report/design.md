# Дизайн

## Контекст
[Объем](proposal.md), [требования](specs/main/spec.md). Готовится только подтверждённый пилот на 10 строк.

## Модули и контракты
Планировщик запускает сборку CSV из хранилища доставок к 08:00; диспетчер получает файл через существующий канал. Назначение остаётся ручным.

## Термины
Новых терминов нет.

## Риски
Ёмкость массового запуска неизвестна. Пилот на 10 строк не подтверждает готовность к массовой нагрузке. Перед расширением нужно вернуться к расчёту ёмкости; до этого массовый запуск остаётся вне объёма. Отложенный вопрос Q-bulk-capacity сохранён в [state](state.md).
