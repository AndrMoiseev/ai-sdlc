# delivery-report

## Проблема и результат
Снизить просрочки: диспетчер использует отчёт до назначения исполнителей.

## Объем
[Спецификация](specs/main/spec.md). Текущий объём — пилот на 10 строк. Ежедневно к 08:00 диспетчер получает CSV с просроченными доставками. Колонки: delivery_id, overdue_minutes, responsible. Назначение исполнителей выполняет диспетчер.

## Исключения
Автоматическое назначение исполнителей и массовый запуск не входят в объём. Ёмкость будущего массового запуска неизвестна; её расчёт отложен до расширения пилота.

## Влияние
Новый CSV для диспетчера; существующая система назначения не меняется.
