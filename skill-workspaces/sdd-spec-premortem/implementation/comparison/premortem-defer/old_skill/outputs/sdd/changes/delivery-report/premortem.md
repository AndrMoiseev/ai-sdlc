## Граница пилота
Текущая подготовка ограничена подтверждённым пилотом на 10 строк. Неизвестная ёмкость массового запуска не блокирует этот объём. Q-bulk-capacity остаётся открытым: к расчёту нужно вернуться перед расширением. Основания — [исходные данные](../../../docs/report.md) и ответ пользователя ниже.

### Ответ пользователя, 2026-10-06
