# Дизайн исправления

## Контекст, цели и исключения

Объем определен в [proposal.md](proposal.md), поведение — в [spec](specs/labels/spec.md). `change.diff` показывает единственную замену значения `submit` в `src/labels.json`; исходный файл подтверждает опечатку.

## Модули и контракты

`src/labels.json` хранит надпись под ключом `submit`. Сохранить ключ и структуру JSON, заменить значение на «Отправить». `docs/labels.md` уже содержит правильное требование и не нуждается в изменении.

## Термины

Новых терминов нет.

## Подход и альтернативы

Точечная замена значения полностью покрывает исправление. Перенос строк или изменение механизма локализации не нужны: предоставленные материалы не указывают на такую проблему.

## Проверка, риски и миграция

При реализации проверить корректность JSON, точное значение `submit` и отсутствие других изменений в diff. В работающем интерфейсе проверить надпись кнопки. В доступных материалах нет формы, обработчика или команды запуска, поэтому проверка интерфейса сейчас не выполнена. Это не мешает определить замену строки по предоставленному diff.

Основной риск — случайно изменить ключ или соседний текст; его покрывает сравнение diff. Миграция данных не требуется. Открытых вопросов о поведении нет.

# Исправление надписи кнопки отправки

## Проблема и результат

В `src/labels.json` значение `submit` содержит опечатку «Отпавить». Требуемая надпись «Отправить» уже установлена в `docs/labels.md`, раздел «Текст интерфейса».

## Объем

Исправить одну строку интерфейса согласно `change.diff`. Затронута capability [labels](specs/labels/spec.md). Новых capabilities нет; существующее требование сохраняется, исправляется несоответствие реализации.

## Исключения

Обработчик отправки, права, доступность и другие надписи не входят в изменение.

## Влияние

Пользователь увидит правильную надпись кнопки. Ключ `submit` и формат JSON сохраняются. Подход описан в [design.md](design.md).

# Текст интерфейса

## Надпись кнопки отправки

```yaml
sdd_record: requirement
id: REQ-submit-label
operation: modify
source:
  kind: specification
  path: docs/labels.md
  requirement: Текст интерфейса
```

В форме отправки кнопка должна называться «Отправить». Исправление затрагивает только буквы надписи; обработчик, права и доступность остаются прежними. Здесь повторено полное существующее требование для исправления реализации; новый контракт не вводится.

### Правильная надпись

```yaml
sdd_record: acceptance
id: AC-submit-label
requirement: REQ-submit-label
conditions: Пользователь открывает форму отправки.
expected: На кнопке отправки отображается «Отправить».
```

### Границы исправления

```yaml
sdd_record: acceptance
id: AC-label-only
requirement: REQ-submit-label
conditions: Исправление сравнивают с исходной версией.
expected: Меняется только надпись «Отпавить» на «Отправить»; обработчик, права и доступность прежние.
```
