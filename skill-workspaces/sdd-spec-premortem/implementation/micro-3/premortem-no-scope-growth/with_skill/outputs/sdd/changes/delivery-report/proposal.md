# Ежедневный отчёт о просрочках

## Проблема и результат

Цель из [report.md](../../../docs/report.md) — снизить просрочки. Получатель — диспетчер доставки; отчёт предусмотрен ежедневно в 09:00. Как отчёт повлияет на действия после назначения исполнителей в 08:30, пока неизвестно; см. [премортем](premortem.md).

## Объем

Черновик общей для обоих вариантов capability [delivery-csv](specs/delivery-csv/spec.md) закрепляет согласованные колонки. Полный объём продукта остаётся открытым до ответа на [Q-report-action](state.md#q-report-action).

## Исключения

Автоматическое назначение остаётся предложением менеджера. Принятие риска не зафиксировано. Ни вариант только с отчётом, ни расширенный вариант не объявлены выбранными. Реализация и план задач не входят в эту порцию работы.

## Влияние

Общий интерфейс — CSV с тремя согласованными колонками. Источники данных, правила расчёта значений и параметры выдачи требуют дальнейшего уточнения. Этот черновик не доказывает достижение цели снижения просрочек.
