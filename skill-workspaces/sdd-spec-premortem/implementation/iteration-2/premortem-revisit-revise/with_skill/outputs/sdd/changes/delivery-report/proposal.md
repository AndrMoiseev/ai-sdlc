# delivery-report

## Проблема и результат
Снизить просрочки: диспетчер использует отчёт до назначения исполнителей.

## Объем
[Спецификация](specs/main/spec.md). Ежедневно до назначения исполнителей в 07:30 диспетчер получает CSV с просроченными доставками. Колонки: delivery_id, overdue_minutes, responsible. Назначение исполнителей выполняет диспетчер.

## Исключения
Автоматическое назначение исполнителей не входит в объём.

## Влияние
Новый CSV для диспетчера; существующая система назначения не меняется.

## Открытый вопрос
Прежний срок 08:00 устарел. Точный новый срок доступности CSV не выбран: [Q-report-time](state.md#время-отчёта). Документ остаётся черновиком.
