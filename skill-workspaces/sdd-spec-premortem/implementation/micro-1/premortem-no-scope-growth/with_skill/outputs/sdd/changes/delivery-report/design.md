# Дизайн независимой части CSV — черновик

## Контекст, цели и исключения

Область задана в [proposal](proposal.md). В доступных материалах есть только описание отчёта и предложение менеджера; исходников реализации нет. Архитектуру существующей системы установить нельзя.

## Модули и контракты

Предлагаемая граница: формирование CSV получает данные доставки и выводит согласованные колонки по [REQ-csv-columns](specs/delivery-csv/spec.md#три-согласованные-колонки). Контракт колонок можно уточнять независимо от будущего решения об автоматическом назначении. Источник данных и механизм запуска пока не определены.

Поле responsible не означает автоматического выбора исполнителя. Алгоритм назначения и изменение назначений не проектируются до выбора объёма пользователем.

## Термины

Имена колонок сохранены из источника. Точные типы и правила вычисления значений ещё не установлены; по одному имени overdue_minutes нельзя закреплять округление и момент расчёта.

## Альтернативы и риски

Предложения менеджера — автоматическое назначение либо принятие риска отчёта без подтверждённой пользы — сохранены в [state](state.md). Ни одно не выбрано пользователем. Возможность полезного действия после 09:00 требует ответа на Q-report-action. До этого нельзя выбрать алгоритм назначения или утверждать, что одного отчёта достаточно.

Проверка независимой части сопоставляет количество и имена колонок с AC-csv-columns. Данные для демонстрации и миграция не заданы; вымышленные доставки не добавляются.
