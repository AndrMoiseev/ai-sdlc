# CSV ежедневного отчёта — частичный черновик

## Проблема и результат

По [источнику](../../../docs/report.md) диспетчеру доставки нужен ежедневный отчёт в 09:00; цель — снизить просрочки. Действие по отчёту пока не определено: назначения происходят в 08:30. Риск разобран в [премортеме](premortem.md). Этот черновик фиксирует только независимую часть контракта CSV.

## Объём

Capability [delivery-csv](specs/delivery-csv/spec.md): три согласованные колонки delivery_id, overdue_minutes, responsible. Этот состав применим к обоим обсуждаемым вариантам поведения.

## Исключения

Автоматическое назначение остаётся предложением менеджера, не требованием. Принятие риска пользователем не зафиксировано. Выбор продукта «только отчёт» тоже не сделан. Расписание не изменено. Код и конфигурация реализации не входят в эту работу.

## Влияние

Зафиксирован состав внешнего CSV. Правила формирования строк и действие диспетчера требуют уточнения; готовность полного контракта и снижение просрочек не подтверждены.
