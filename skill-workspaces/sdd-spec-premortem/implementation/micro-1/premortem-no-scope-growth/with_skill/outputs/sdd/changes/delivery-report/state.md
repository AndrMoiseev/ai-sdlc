### Ближайший вопрос

```yaml
sdd_record: question
id: Q-report-action
text: Какое действие диспетчер должен выполнить по отчёту в 09:00, чтобы снизить просрочки, если исполнители уже назначены в 08:30?
blocking: true
status: open
```

Ответ определит требуемый результат и поможет выбрать объём автоматизации. Вопрос блокирует зависимые требования и готовность полного комплекта к ревью, но не описание согласованных колонок. Вариант для обсуждения — использование отчёта для пересмотра назначений после 09:00; возможность и польза такого действия не подтверждены.
