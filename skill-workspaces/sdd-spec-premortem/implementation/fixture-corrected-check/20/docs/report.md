# Ежедневный отчёт
Получатель: диспетчер доставки. Отчёт ежедневно в 08:00. CSV: delivery_id, overdue_minutes, responsible. Цель — снизить просрочки. Диспетчер назначает исполнителей в 08:30. Пользователь подтвердил пилот на 10 строк. Массовый запуск не входит в текущий объём; расчёт ёмкости отложен до расширения.
