# Независимая часть CSV — черновик

## Основание и границы

[Описание отчёта](../../../docs/report.md) подтверждает три колонки CSV для обоих вариантов поведения. Эта часть не зависит от выбора автоматического назначения. Документ сохраняет известное и предложения для будущей спецификации; он не является согласованным нормативным комплектом.

## Подтверждённый состав

| Колонка | Что известно |
|---|---|
| delivery_id | Имя колонки согласовано. Формат идентификатора не описан. |
| overdue_minutes | Имя колонки согласовано. Правила расчёта и округления не описаны. |
| responsible | Имя колонки согласовано. Представление исполнителя и отсутствие значения не описаны. |

## Предложение заголовка

```text
delivery_id,overdue_minutes,responsible
```

Порядок взят из исходного перечисления, запятая предложена как разделитель. Эти детали не объявляются отдельным решением пользователя. Пример содержит только заголовок: фактических данных доставок нет.

## Предлагаемые проверки общей части

- В описании CSV присутствуют ровно три согласованных имени: delivery_id, overdue_minutes, responsible.
- Состав колонок одинаков для варианта только с отчётом и варианта с автоматическим назначением, если последний будет выбран пользователем.
- Наличие responsible в CSV само по себе не задаёт назначение или переназначение исполнителя.

## Детали для последующей спецификации

После определения действия по отчёту уточнить состав строк, момент среза данных, формулу overdue_minutes и представление responsible. При подготовке контракта экспорта определить кодировку, разделитель, экранирование, порядок строк и обработку пустых значений. Эти детали оставлены открытыми, чтобы не выдать технические предположения за согласованные требования. Ближайший вопрос остаётся [Q-report-action](state.md#действие-по-отчёту).
