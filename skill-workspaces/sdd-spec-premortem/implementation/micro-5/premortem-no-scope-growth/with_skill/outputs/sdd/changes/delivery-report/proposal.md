# Ежедневный отчёт доставки

## Проблема и результат

По [исходному описанию](../../../docs/report.md) диспетчеру нужен ежедневный отчёт в 09:00 с целью снизить просрочки. Какое действие после получения отчёта приведёт к этому результату, пока не установлено; см. [премортем](premortem.md).

## Объем

Продолжена независимая часть черновика: [контракт трёх колонок CSV](specs/delivery-csv/spec.md). Их состав согласован в исходном описании для обоих вариантов поведения. Данный комплект не является согласованной спецификацией всей функции.

## Исключения

Автоматическое назначение остаётся предложением менеджера. Принятие риска пользователем не зафиксировано. Изменение времени отчёта также не выбрано. Реализация и план задач не входят в эту порцию работы.

## Влияние

Уточнён состав выходного CSV. Источник строк, трактовка значений и способ доставки файла требуют дальнейшего описания после уточнения назначения отчёта. Существующая реализация в доступных материалах не представлена.
