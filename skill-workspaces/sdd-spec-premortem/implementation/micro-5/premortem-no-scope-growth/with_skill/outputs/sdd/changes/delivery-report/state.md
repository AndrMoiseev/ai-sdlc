## Сохраненные решения и предложения

Основания: [report.md](../../../docs/report.md), [manager-note.md](../../../docs/manager-note.md) и текущий запрос пользователя. Пользователь прямо сообщил: «Моего решения по этим вариантам ещё нет». Три колонки согласованы для обоих вариантов по report.md. Выбор C сделан агентом по поручению выбрать действие; он не является согласием пользователя на A или B.

Предложение менеджера A — автоматическое назначение исполнителей. Предложение менеджера B — принятие риска бесполезного отчёта. Оба остаются предложениями без согласования. Агент предлагает сначала установить полезное действие по отчёту: возможная корректировка назначений после 09:00 требует подтверждения и не включена в требования.

### Ближайший вопрос

```yaml
sdd_record: question
id: Q-report-action
text: Какое решение должен принимать диспетчер по отчёту в 09:00, если исполнителей он назначает в 08:30?
blocking: true
status: open
```

Ответ определит полезный результат и границы поведения до выбора автоматического назначения или принятия риска. Вопрос блокирует зависимую часть и готовность комплекта к ревью, но не состав трёх колонок CSV.

### Детали CSV

```yaml
sdd_record: question
id: Q-csv-details
text: Каковы источник и отбор строк, типы и пустые значения трёх полей, расчёт просрочки и параметры сериализации CSV?
blocking: false
status: open
reason: Сейчас фиксируется только уже согласованный состав колонок; детали зависят от назначения отчёта.
return_at: После ответа на Q-report-action, до завершения спецификации CSV и предложения ревью.
```
