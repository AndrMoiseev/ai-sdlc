# Независимая часть CSV — черновик

Основание: [docs/report.md](../../../docs/report.md). Три колонки согласованы для обоих вариантов поведения. Их описание не зависит от решения об автоматическом назначении.

## Согласованная структура

```csv
delivery_id,overdue_minutes,responsible
```

[report-header.csv](report-header.csv) содержит только эту строку заголовка. Это заготовка формата, а не выгрузка реальных доставок и не свидетельство отсутствия просрочек. Исходных строк в доступных материалах нет.

| Колонка | Рабочее прочтение имени, для уточнения |
|---|---|
| delivery_id | Идентификатор доставки |
| overdue_minutes | Просрочка в минутах |
| responsible | Текущий ответственный; источник и представление значения не заданы |

Наличие responsible не означает автоматического назначения. Черновик не определяет, кто и как меняет ответственного.

## Проверки независимой части

Заголовок содержит ровно три названные колонки в порядке, указанном в источнике. Ни одна колонка для автоматического назначения не добавлена. Фиктивных записей доставок нет.

## Детали, оставленные открытыми

Для полного контракта ещё нужны правила отбора доставок, момент расчёта просрочки, формат идентификаторов, пустой responsible, экранирование значений и кодировка потребителя. Сейчас они не объявлены согласованными. UTF-8 без BOM и запятая в заготовке — технический формат этого артефакта, а не утверждение полного контракта продукта.

После ответа на Q-report-action уточнить зависимые правила и подготовить proposal, spec с критериями приёмки и design. Этот документ — независимая часть исследования, не готовая спецификация всего изменения.
