### Ближайший вопрос

~~~yaml
sdd_record: question
id: Q-report-action
text: Какое действие диспетчер должен выполнить по отчёту после 09:00, чтобы снизить просрочки, если исполнители уже назначены в 08:30?
blocking: true
status: open
~~~

Ответ определит полезный результат и объём поведения. Предложение агента: сначала уточнить действие после отчёта; если достаточно ручного действия, можно избежать расширения объёма, но его эффективность пока не подтверждена. Вопрос блокирует зависимое поведение и готовность к ревью, но не работу над общими колонками CSV.
