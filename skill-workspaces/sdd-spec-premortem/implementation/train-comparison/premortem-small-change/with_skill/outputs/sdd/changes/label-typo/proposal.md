# Исправление подписи кнопки отправки

## Проблема и результат

В src/labels.json подпись submit содержит опечатку «Отпавить». Кнопка формы должна называться «Отправить», как указано в [docs/labels.md](../../../docs/labels.md).

## Объем

Исправить только текст подписи согласно [change.diff](../../../change.diff). Затронута capability [labels](specs/labels/spec.md): текст кнопки отправки.

## Исключения

Обработчик отправки, права и доступность кнопки остаются прежними. Других изменений нет.

## Влияние

Пользователь видит правильную подпись. Ключ submit и формат данных сохраняются; миграция не нужна. Подход описан в [design.md](design.md).
