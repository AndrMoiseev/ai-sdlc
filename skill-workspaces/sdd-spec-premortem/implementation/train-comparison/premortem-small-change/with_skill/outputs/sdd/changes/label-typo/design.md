# Дизайн исправления подписи

## Контекст, цели и исключения

Цель и границы описаны в [proposal.md](proposal.md), требование и критерии — в [specs/labels/spec.md](specs/labels/spec.md). Доступные исходники содержат src/labels.json со значением submit «Отпавить». Представленный change.diff заменяет только это значение.

## Модули и контракты

В src/labels.json сохраняются ключ submit и строковый тип значения. Обработчик, права и доступность кнопки не меняются. Исходников формы и обработчика в предоставленных материалах нет; выполнение интерфейса не проверялось.

## Термины

Новых терминов нет.

## Подход

Заменить значение submit на «Отправить» в точности по change.diff. Отдельный механизм подмены текста не нужен: исправление самого значения устраняет опечатку без изменения структуры данных. Миграция не требуется.

## Проверка и риски

При реализации сверить diff: единственная правка — указанная строка. Проверить корректность JSON и точное значение submit. При доступности приложения проверить отображаемую подпись по AC-submit-label и сохранение поведения по AC-submit-behavior. Эти проверки реализации в рамках подготовки документов не выполнялись.

Существенных неопределённостей в заданном объёме нет. Премортем завершён, итог сохранён в [state.md](state.md).
