# Ежедневный отчёт о доставках

Черновик: цель использования требует уточнения.

## Проблема и результат

Источник: [docs/report.md](../../../docs/report.md). Получатель — диспетчер доставки. Цель — снизить просрочки. Запрошен ежедневный CSV в 09:00 с полями delivery_id, overdue_minutes, responsible.

Диспетчер назначает исполнителей в 08:30. Отчёт поступает после этого решения. Неизвестно, какое действие по отчёту должно снижать просрочки. Получение CSV само по себе не подтверждает достижение цели.

## Объем

Новая capability [delivery-report](specs/delivery-report/spec.md): ежедневный отчёт о просроченных доставках и ответственных. Существующих спецификаций и исходников продукта в доступных материалах нет. [Design](design.md) содержит предварительный подход; [state](state.md) — блокирующие вопросы.

## Исключения

Автоматическое назначение исполнителей, изменение расписания 08:30, реализация и развёртывание не входят в запрос. Перенос отчёта на время до 08:30 не согласован.

## Влияние

Появляется CSV для диспетчера. Потребуются сведения о доставках, сроках и ответственных. Источник, правила расчёта, канал передачи и часовой пояс неизвестны. Оценка интеграций ограничена отсутствием материалов реализации.
