# Дизайн

## Контекст
[Объем](proposal.md), [требования](specs/main/spec.md).

## Модули и контракты
Планировщик запускает сборку CSV из хранилища доставок; диспетчер получает файл через существующий канал до назначения исполнителей в 07:30. Точное время готовности отчёта и зависимое расписание сборки пока не определены: открыт Q-report-time в [state](state.md). Назначение остаётся ручным.
