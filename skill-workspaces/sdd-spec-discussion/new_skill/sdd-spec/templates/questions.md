# Вопросы изменения

Храните здесь открытые и закрытые вопросы. Их порядок отражает зависимости:
результат и границы раньше деталей. Удалите пример, когда записываете реальные вопросы.

### Режим выполнения

```yaml
sdd_record: question
id: Q-execution-mode
text: Какой режим выполнения использовать по умолчанию?
blocking: true
status: open
```

Причина: выбор меняет поведение запуска без параметров.
Варианты и рекомендация: опишите варианты с существенными компромиссами.
Затронутые документы: дайте ссылки на существующие положения черновика.
Предложение: [запись журнала](decisions.md#режим-выполнения).

Для открытого неблокирующего вопроса добавьте `reason` и конкретный `return_at`.
При закрытии задайте `status: resolved` и `resolution: decisions.md#режим-выполнения`
либо путь к проверенному источнику. Это строка с относительным путём от каталога
изменения, без Markdown-обёртки; файл должен существовать, якорь после `#` непустой.
Сохраните исходный вопрос, ответ и ссылку на основание; не удаляйте историю.
