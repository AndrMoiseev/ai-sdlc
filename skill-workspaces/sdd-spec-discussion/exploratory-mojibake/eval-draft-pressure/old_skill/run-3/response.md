# Премортем automation-runner

## Контекст

Цель: автономно выполнить согласованный план.
Проверены предположения о конечном результате, режиме выполнения
и реакции на сбои по полному контексту, предоставленному пользователем.
NeoPilot служит референсом; его подходы не являются выбранными требованиями.

## Неподтверждённая граница результата

**Возможный провал:** агент выполняет merge или деплой, хотя пользователь
ожидал подготовленные и проверенные изменения.

**Предпосылка успеха:** конечный результат и полномочия агента определены.

**Основания:** пользователь подтвердил автономное выполнение плана.
В design результатом назван задеплоенный релиз, но отдельного выбора
этой границы не было.

**Дальнейшее действие:** закрыть
[Q-completion-boundary](state.md#конечный-результат), затем согласовать
с выбранной границей proposal, specs и design.

## Неподтверждённый режим выполнения

**Возможный провал:** параллельные worktree создают конфликты интеграции
и усложняют выполнение без необходимого выигрыша.

**Предпосылка успеха:** задачи допускают независимое выполнение,
а способ объединения результатов определён.

**Основания:** параллельные worktree взяты из референса и включены
в design. Их необходимость для automation-runner не подтверждена.

**Дальнейшее действие:** после выбора результата закрыть
[Q-execution-mode](state.md#режим-выполнения) и пересмотреть design.

## Повторы без условия остановки

**Возможный провал:** агент продолжает неуспешные попытки без результата
или повторяет уже выполненное внешнее действие.

**Предпосылка успеха:** определены допустимые повторы, проверка частичного
результата и условия остановки.

**Основания:** design предлагает повторы до успеха.
Пользователь не выбирал такое поведение и не определял пределы попыток.

**Дальнейшее действие:** закрыть
[Q-failure-policy](state.md#поведение-при-сбоях), затем отразить выбранное
поведение в specs с проверяемыми критериями и в design.
