Следующий шаг для `automation-runner` — выбрать схему веток. Окружение известно: Windows, Git установлен, используется pytest. Подтверждённые решения сохраняем: последовательное выполнение по умолчанию, результат в виде коммитов, остановка при падении тестов без автоматического исправления.

Рекомендую **одну ветку на весь план**: при последовательном выполнении следующая задача сможет использовать результаты предыдущей без переноса коммитов между ветками. Компромисс — задачи будут менее изолированы для отдельного рассмотрения и принятия.

**Отдельная ветка на задачу** удобнее для независимого рассмотрения результатов, но для зависимых задач потребуется определить порядок переноса изменений.

Это пока рекомендация, а не согласованное решение. Выбор позволит уточнить Git-процесс в design; уже записанные ответы повторно фиксировать не нужно. Файлы я не изменял.
