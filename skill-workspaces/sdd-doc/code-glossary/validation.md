# Проверка глоссария по кодовой базе

Дата: 2026-09-28. Изменение основано на обратной связи пользователя о результате
в Stepan: документ должен управлять именованием в коде, иметь доменные таблицы
и отличать допустимые имена от встречающихся синонимов.

## Изменения

- Исследование реализации и её потребителей предшествует сверке с документацией.
- Каждому домену соответствует таблица: название, описание, допустимые имена в коде, синонимы.
- Конкурирующие имена требуют решения; наличие имени в коде не разрешает все варианты.
- Глоссарий содержит правила повторного использования понятий и ввода новых только по спецификации.
- Скилл добавляет указатель в существующие инструкции агентам в пределах области задачи.

## Проверки и артефакты

`eval_skill.py`: 9 проверок пройдено, ошибок нет. Два предупреждения о положительных
и отрицательных триггерах неприменимы к выбранному явному вызову. Исходная команда
uv не смогла скачать PyYAML; проверка выполнена через `uv run --offline --no-project python`
с уже установленным PyYAML и `PYTHONUTF8=1`. JSON содержит шесть сценариев.

В отдельных временных проектах выполнены три прогона native Codex с новым контекстом:
старая и новая версии на сценарии 5, новая версия под давлением срока на сценарии 6.
Агентам передавались только запрос, отдельная фикстура и назначенная версия скилла.
Каждый сообщил, что до чтения назначенного скилла его инструкции не были видимы.
Изменений исходного кода фикстур нет; равенство файлов проверено.

Результаты и независимые оценки доступны в [отчёте](review.html).
Оценки: сценарий 5 — старая версия 5/9, новая 8/9; сценарий 6 — новая 3/4.
Все критерии содержимого новой версии пройдены. Непройденные критерии новой
версии относятся к недоказанному порядку чтения: самоотчёт не заменяет трассу.
Сводные средние сравнивают разные наборы сценариев; для прямого сравнения
используй только пару сценария 5, а не общую дельту benchmark.json.
Файлы `transcript.md` содержат отчёты исполнителей о чтении файлов, а не полные
трассы инструментов. Метрики времени и токенов недоступны и записаны как null.

## Интерпретация и ограничения

Старая версия также нашла DispatchBatch и противоречие срока: эти критерии
не отличают версии на маленькой фикстуре. Отличие новой версии — доменные таблицы,
явный контракт допустимых имён и правила для агента, который будет писать код.
Оба результата новой версии оставляют неопределённую терминологию вопросами.

Это точечная проверка, не полный цикл BinEval: пять повторов микротестов,
контроль без инструкций, train/holdout gate и повторные прогоны прежних сценариев
1–4 не выполнены. Автоматическое обнаружение намеренно не проверялось.
Новый скилл не запускался на полном репозитории Stepan; его глоссарий не изменён.
