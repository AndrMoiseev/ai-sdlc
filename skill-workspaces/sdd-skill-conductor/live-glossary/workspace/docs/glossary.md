# Глоссарий сервиса резервирования

Глоссарий составлен по материалам, предоставленным пользователем в запросе.
Действующее соглашение и предложение о будущем изменении указаны отдельно.

## Резерв

Временное закрепление количества товара за [заказом](#заказ).

- Статус: действующее соглашение.
- Допустимое сокращение: РЗ.
- Нежелательный синоним: «бронь», поскольку его путают с предзаказом.
- Источник: действующее соглашение, приведённое пользователем в запросе.

### Предложение ADR — `proposed`

Черновик ADR предлагает в будущем заменить временный резерв бессрочным
выделением. Это предложение о будущем состоянии; оно не изменяет действующее
определение резерва. Бессрочное выделение не является действующим синонимом
резерва.

Источник: описание черновика ADR со статусом `proposed`, предоставленное
пользователем в запросе. Отдельный файл ADR не предоставлен.

## Заказ

Оформленная потребность покупателя в товарах.

- Статус: действующее определение.
- Источник: определение, предоставленное пользователем в запросе.

## Границы проверки

Определения сверены только с материалами запроса. По сообщению пользователя,
других документов и файлов реализации в проекте нет; проверка по реализации
и подробному описанию домена не проводилась.

Определение предзаказа в материалах отсутствует; термин упомянут только для
объяснения нежелательности синонима «бронь». Открытых вопросов по действующим
определениям резерва и заказа нет. Решение о принятии предложения ADR остаётся
за рамками действующего соглашения.
