# Интеграция humanizer-ru, 2026-10-02

Изменены инструкции sdd-spec и sdd-doc. После завершённой порции правок
редактор со свежим контекстом обрабатывает русскую авторскую прозу; отдельный
слепой проверяющий проверяет кандидат. Смысл, термины и структура защищены.
Исходные отчёты и USER-ответы сохраняются дословно. Для sdd-spec проход предшествует
снимкам версии, а стилистические правки нормативного комплекта устаревают ревью.

## Выполненные проверки

- Контракт пакета sdd-spec: `python skills/sdd-spec/scripts/run.py test -q -k package_contract`,
  5 passed, 127 deselected. Проверены метаданные, явный вызов, комплектность и ссылки.
- sdd-doc: quick_validate успешен; eval_skill даёт 8/10, без ошибок. Два предупреждения
  относятся к прежнему описанию явно вызываемого скилла, а не к этой правке.
- Общий quick_validate не поддерживает существующий `disable-model-invocation`
  sdd-spec; для него использована собственная контрактная проверка.
- Локальные ссылки проверены. В glossary.md ссылка с текстовым путём «путь» является
  примером для автора, а не ресурсом пакета. Временных окружений и кэшей в пакетах нет.
- Независимое чтение sdd-spec на пяти сценариях выявило риск пропуска checkpoint
  и пропуска YAML-значений в линтере. Уточнены порядок сохранения, адреса извлечений
  и проверка актуальности редактуры перед review_consent.
- Независимое чтение sdd-doc на трёх сценариях подтвердило защиту имён и статусов.
  Уточнены возобновление незавершённой редактуры, защита незатронутых определений
  при точечной задаче и возможность показать непроверенный черновик для разбора блокера.

## Реальная редактура тестового документа

Свежий редактор прочитал humanizer-ru, полный справочник и corrections.md.
В `fixture.md` разрешена только проза перед YAML; остальные части защищены.
Редактор предложил одну замену: «осуществляет выполнение повторной отправки»
на «повторно отправляет». Результат сохранён отдельно в `candidate.md`.

Линтер вызван редактором через stdin с Python `-B`: 0 errors, 1 warning,
exit 0. Предупреждение о повторе «отправляет / не отправляется» сохранено:
оно выражает действие и запрет при противоположном условии. Редактор сверил
неизменность YAML, цитаты, таблицы, идентификаторов и числового ограничения.

Другой свежий агент прочитал только кандидат и справочник с ограничениями жанра.
Подтверждённых находок нет. Исходник и таблица находок ему не передавались.

## Границы доказательств

Это один фактический редакторский проход и независимые статические проверки,
а не полный сравнительный benchmark sdd-spec/sdd-doc. Baseline сохранён локально
только для сравнения исходников с установленными копиями; поведенческий контроль
без нового правила и пять повторов на вариант не выполнялись. Нет runtime-прогона
Claude Code и полного сценария от запроса пользователя до согласованного плана.
Свежие агенты не наследовали беседу, но видели системный каталог скиллов и инструкции
проекта: полной изоляции файлов и обнаружения не заявляем. Время и токены не измерялись.

Сценарии дальнейших проверок включены в evals/manual.md обоих пакетов.
