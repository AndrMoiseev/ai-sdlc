# Повторная отправка

Система повторно отправляет уведомление только после
получения согласия пользователя. При отсутствии согласия уведомление не отправляется.
Допускается не более 3 попыток. Возможность доставки после третьей попытки неизвестна.

Термин «Уведомление» соответствует `Notification`; его идентификатор `notification_id`.

```yaml
sdd_record: acceptance
id: AC-notification-consent
requirement: REQ-notification-consent
conditions: Пользователь не дал согласия
expected: Уведомление не отправляется
```

Цитата пользователя: «Не меняйте ограничение в 3 попытки».

| Термин | Определение | Имена в коде | Источник |
|---|---|---|---|
| Уведомление | Сообщение получателю о событии | `Notification` | `src/notification.py` |
