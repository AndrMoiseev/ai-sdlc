# Адаптер произвольного агента

Используй эту ветку, если текущий агент не Codex и не Claude Code либо среда неизвестна. Явная просьба «используй sdd-spec» запускает скилл. Не предполагай поддержку специальных команд, каталогов установки или политики из метаданных.

Выполняй флоу доступными средствами среды. Перед зависимым шагом установи, доступны ли исходные материалы, запись файлов, запуск команд, нужные скиллы и отдельные свежие контексты. Наличие установленного CLI не определяет текущего агента. Если файлы недоступны, запроси нужные материалы; подготовленный в ответе текст обозначай как несохранённый черновик.

Задание независимому участнику опиши прозой: цель, источники, ограничения, разрешённые действия и формат результата. Передай ему только задание и материалы, без истории автора и выводов других участников. Используй подтверждённый механизм отдельного контекста; названия инструментов и параметры других сред не предполагаются. Просьбу работать только на чтение отличай от технического ограничения прав.

Если независимый запуск недоступен, сохрани статус incomplete и укажи, какой этап не выполнен. Для ревью применяй предусмотренный флоу порядок восстановления или явного waiver; для согласованной гуманизации — [её контракт](editorial-pass.md), без блокировки основного процесса. Самопроверка не заменяет независимую редактуру или ревью. Продолжай работу, не зависящую от отсутствующей возможности.

Сохраняй checkpoint на смысловых границах. Порог заполнения контекста применяй только при достоверной метрике среды; отсутствие измерения укажи явно. Для продолжения достаточно просьбы «используй sdd-spec, продолжи <change-id> в <repo>» и доступных документов по [resume](../flows/resume.md).
