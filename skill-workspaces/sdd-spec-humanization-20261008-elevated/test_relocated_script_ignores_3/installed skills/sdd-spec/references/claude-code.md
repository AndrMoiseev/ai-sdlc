# Адаптер Claude Code

Явный вход — `/sdd-spec`. Frontmatter `disable-model-invocation: true` оставляет запуск пользователю. Копируй весь пакет в `.claude/skills/sdd-spec/` проекта либо `~/.claude/skills/sdd-spec/` пользователя, проверив отсутствие конфликта. Контракт и пути описаны в [Claude Code Skills](https://code.claude.com/docs/en/skills).

Для ревью используй обычного нового субагента с отдельным контекстом, передай готовое задание, нормативные документы и релевантные источники. Не выбирай fork разговора и не предварительно загружай пользовательский sdd в рецензента: ему нужны инструкции задания, а не авторский workflow. Различие контекстов и разрешения описаны в [Claude Code Subagents](https://code.claude.com/docs/en/sub-agents).

Если интерфейс позволяет задать `tools`, ограничь его чтением (`Read`, `Grep`, `Glob`), без Write/Edit и произвольной записи через Bash. `permissionMode` сам по себе не означает read-only: используй доступный allowlist инструментов и инструкцию чтения. Не перезаписывай пользовательские определения агентов и settings ради адаптера. Отчет возвращается основному агенту, который сохраняет его.

При отсутствии чистого контекста или возможности независимого запуска сообщи ограничение и incomplete; предложи восстановить среду либо явное исключение текущего комплекта. Не называй собственную повторную оценку независимым ревью. Если ограничены только слоты, запускай линзы последовательно, сохраняя одинаковые входы.

При достоверной метрике заполнения выше 70% сохрани документы и предупреди; ровно 70% порог не пересекает. Без метрики продолжай смысловые checkpoints и не выдавай предположение за измерение; универсальный hook не обещается. См. [resume](../flows/resume.md).

На 2026-09-29 `claude --version` недоступна в проверенной среде (команда отсутствует в PATH). Адаптер сверен с официальной документацией; минимальная локально проверенная версия не установлена, runtime и сквозной пилот не заявляются. До эксплуатации проверь `claude --version` и фактические интерфейсы установленной версии.
