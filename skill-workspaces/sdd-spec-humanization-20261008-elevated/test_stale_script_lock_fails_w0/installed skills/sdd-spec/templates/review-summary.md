# Сводка ревью

Для каждой находки добавьте в findings объект с finding (полный ключ run-id/lens-id/FIND-ID), related_to (список прежних ключей) и duplicates (список ключей дублей); пустые связи записываются как [].

Сохраните ссылки на исходные отчеты, отдельно покажите расхождения линз, текущую актуальность и необходимые решения. Связь related_to не переносит пользовательское решение. Исходные отчеты остаются неизменными.
