# Адаптер Codex

Явный вход — `$sdd-spec` либо выбор скилла. Поставляй весь каталог вместе с `agents/openai.yaml`, где `policy.allow_implicit_invocation: false`. Для проектного подключения используй `.agents/skills/sdd-spec/`, для личного — `~/.agents/skills/sdd-spec/`; существующую установку и настройки сначала проверь. Контракт метаданных и обнаружения описан в [OpenAI Build skills](https://learn.chatgpt.com/docs/build-skills).

Для каждого независимого рецензента создай новый контекст. Если доступный API предоставляет `fork_turns`, передай `fork_turns: "none"`; значение по умолчанию может наследовать историю. Передай подготовленное задание и пути напрямую. Не используй продолжение или fork авторской сессии. В другом интерфейсе сначала проверь способ изоляции, а не предполагаемый параметр. Настройки отдельных агентов описаны в [OpenAI Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents).

Включай доступный read-only sandbox/набор инструментов. В технически проверенном `codex-cli 0.159.0` команда `codex exec --help` содержит `--sandbox read-only`, `--ephemeral`, `--cd`, чтение задания из stdin. Новый `codex exec --sandbox read-only --ephemeral --cd <repo> -` допустим как отдельный процесс при разрешенном запуске и доступной аутентификации; не используй его `resume` или `fork`. Захвати stdout основным агентом; рецензент не пишет отчет. Не меняй глобальные настройки ради запуска.

Если native API не ограничивает права записи, явно поручай только чтение и сообщай, что это инструкция, а не жесткая изоляция файловых прав. При отсутствии чистого контекста или доступного отдельного запуска зафиксируй incomplete и предложи восстановить возможность либо явный waiver. Самопроверка не заменяет независимого рецензента. При лимите агентов выполни линзы последовательно.

Сохраняй checkpoint при достоверно измеренном заполнении контекста выше 70%; ровно 70% не пересекает порог. Если среда не предоставляет метрику, используй смысловые checkpoints и честно укажи отсутствие измерения. Универсальный hook или вычисление процента по длине переписки не предполагается. Правила и промпт продолжения — в [resume](../flows/resume.md).

Техническая сверка версии и CLI выполнена 2026-09-29; справка вернула предупреждения о недоступной очистке временного PATH-каталога, но версия и параметры прочитаны. Это не сквозной прогон SDD и не доказательство поведения invocation в каждом клиенте Codex.
