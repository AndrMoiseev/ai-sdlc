# Проверка поддержки Codex и Claude Code

Дата: 2026-09-28.

Изменён [skill-conductor](../../.agents/skills/skill-conductor/SKILL.md):
встроенные субагенты текущего харнеса используются при доступной изоляции;
для CLI добавлены общий адаптер и `--harness auto|codex|claude-code`.

Выбор CLI: аргумент → `SKILL_CONDUCTOR_HARNESS` → маркеры текущей сессии →
единственный установленный CLI. Неоднозначность и отсутствие выбранного CLI
возвращают ошибку; переключения провайдера без указания пользователя нет.
Отсутствие CLI не блокирует доступных встроенных субагентов.

## Изменения

- `run_task.py` выполняет подготовленный поведенческий сценарий и сохраняет
  ответ, JSONL-события, stderr, метаданные и измеренное время.
- `run_eval.py` запускает проверки выбора в отдельных временных каталогах.
  Ошибки выполнения не засчитываются как корректное отсутствие вызова.
- `improve_description.py` и `run_loop.py` используют выбранный CLI без
  обязательной зависимости от Anthropic SDK. Контрольная выборка скрыта от редактора.
- Для скиллов с явным вызовом проверки автоматического выбора и оптимизация
  описания пропускаются; поведенческие сценарии остаются доступными.
- Неизвестные метрики сохраняются как `null`; число символов больше не выдаётся
  за число токенов. В статистике учитываются только известные измерения.
- Запуск процессов и чтение UTF-8 проверены на Windows; `select()` на pipe
  заменён переносимым обменом через stdin/stdout.

## Ограничения

Claude Code CLI в этой среде отсутствует: его ветка проверена на моделируемых
событиях и процессах, без обращения к живому Claude Code. Живой цикл оптимизации
описания не запускался; его маршрутизация и обработка ошибок проверены офлайн.

Положительная проба детектора содержала явный вызов: результат подтверждает
работоспособность адаптера, но не качество автоматического выбора конкретного
скилла. Один прогон глоссария также не доказывает преимущество над baseline.

В живых запусках использован настроенный CLI model default; точный идентификатор
модели не получен из этих событий и не приписан задним числом. Пользовательские
настройки и авторизация CLI сохранены, поэтому временный каталог сам по себе
не гарантирует отсутствия пользовательских скиллов и инструкций.
