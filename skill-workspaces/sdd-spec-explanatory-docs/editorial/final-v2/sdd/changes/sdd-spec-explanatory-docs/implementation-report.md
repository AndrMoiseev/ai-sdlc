# Реализация поясняющих документов

Изменения внесены в skills/sdd-spec: маршрут explain, контракт пояснения,
шаблоны пояснения и продолжения превью, интеграция с draft/revise/resume,
документация зависимостей и правила редактуры. В контракт пакета включены
новые ресурсы. Девять поведенческих сценариев и четыре процедуры реальной
проверки добавлены к существующим evals.

archify, формат sdd v1, скрипты check и snapshot не изменялись. Установленные
копии скиллов не обновлялись. Посторонние изменения рабочего дерева сохранены.

## Область проверки

Пользователь поручил выполнить tasks.md, затем ограничил проверки:

> только локальные проверки

До этого автоматическая проверка разрешений отклонила сравнительный запуск
Codex CLI с копией скилла и синтетическими документами как возможную передачу
приватных данных во внешний сервис. После уточнения такие запуски не выполняются.
Отдельные baseline/candidate прогоны, micro-tests, pressure-tests, поведенческое
сравнение и его benchmark/viewer не заявляются выполненными. Подготовленные
сценарии позволяют вернуться к ним при отдельном поручении.

Локальная регрессия исходного пакета: `python skills/sdd-spec/scripts/run.py test`,
131 passed, 1 skipped. Кэш штатного запускателя находится вне пакета.
Первая попытка package-contract выявила ссылки на будущие артефакты внутри
кодового примера шаблона. Проверка ссылок теперь исключает fenced-примеры,
продолжая проверять ссылки инструкций на реальные ресурсы пакета.

Остальные локальные результаты и редактура фиксируются после завершения.
