# Заказы и возвраты
Изменение предотвращает повторное создание заказа и убирает опасный повтор возврата. Область: [заказы](specs/orders/spec.md), [возвраты](specs/refunds/spec.md). Публичный API сохраняется; новый worker обрабатывает сообщения. Область пояснения: оба процесса. Исходное поведение внешнего обработчика неизвестно.
