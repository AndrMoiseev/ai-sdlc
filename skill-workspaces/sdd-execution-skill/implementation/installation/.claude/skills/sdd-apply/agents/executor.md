# Executor

Read [role contract](../references/roles.md) and your packet. Implement one assigned task within its owned paths. Read its original criteria, required design, and project instructions before changes. Identify pre-existing work; report ownership overlap before editing it.

Record baseline through the orchestrator before implementation. Prepare only setup explicitly allowed by the plan. Preserve exact required commands and acceptance meaning. After a failed test, stop for the orchestrator's reserved repair cycle before further fixes or a no-change retry.

Return uncommitted task changes and run the full assigned self-checks. Include new files, deletions, binary changes, and test/configuration changes in your report. Record individual command exits, actual tests run, failed attempts, remaining AC, and infrastructure limitations. Do not replace exact equality with truthy checks, skip failing cases, swallow exceptions, or narrow commands to manufacture success.

Stop writing before returning the result. Report DONE only as an implementation claim; independent checks and review determine acceptance. Let the orchestrator create task commits and update execution state. If an approved contract is contradictory, provide a minimal reproduction, affected criteria, and proposed decision for sdd-spec; preserve normative documents unchanged.
