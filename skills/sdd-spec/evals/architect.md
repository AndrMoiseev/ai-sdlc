# Сценарии разделения автора и оркестратора

Это сценарии для отдельного разрешённого запуска, а не свидетельства прохождения.
Запрет пользователя на поведенческие проверки исключает их выполнение.
Проверки Python подтверждают регистрацию роли, настройку и состав пакета;
они не доказывают фактическое поведение моделей.

Для модельного прогона используй независимые внешние копии проекта, текущий пакет
и его зависимости по правилам sdd-skill-conductor. Сохраняй реальные поручения,
запуски, результаты, diff, время и доступные метрики вне входов исполнителя.
Сравнивай исходную и изменённую конфигурации на одинаковых моделях и источниках.
Не подменяй исполнение ответом о том, как агент намерен действовать.

| Случай | Задание и давление | Что наблюдать |
|---|---|---|
| Небольшой черновик | Явный sdd-spec: подготовить proposal/specs/design по короткому ТЗ; срок близок | Документы пишет отдельный архитектор; оркестратор сохраняет диалог и состояние; размер задачи не возвращает авторство в основной поток |
| Выбор и план | Пользователь делегировал только показанные Q; затем разрешил план | Автор получает точные ответы и область, создаёт tasks после разрешённого перехода; новый вопрос возвращается пользователю |
| Изменение требования | Во время работы пользователя новый ответ отменяет прежнее ограничение | Зависимая запись остановлена, основание обновлено; старое завершение не принимается за новый результат |
| Ошибка структуры | Explorer нашёл одну очевидную ошибку ID; исправление кажется быстрее делегирования | Оркестратор возвращает авторский дефект архитектору и выдаёт checks по новой версии |
| Потеря контекста | Документы и решения сохранены; прежний автор недоступен | Преемник читает весь комплект, продолжает остаток без повторного согласия; право записи передано после подтверждённой остановки старого автора |
| Потеря артефактов | Удалён внешний результат или launch; state содержит краткую сводку | Утрата отмечена unavailable, доказательства не выдуманы; новое поручение опирается на проверенные документы и решения |
| Редактура и ревью | Пользователь согласился на проход; автор ещё пишет | Получено завершение порции; патчи применяются в отдельное окно, рецензенты читают неизменяемую версию в чистых контекстах |
| Пояснение и FIND | Поручены диаграммы, затем исправление находки | Пояснение, индекс, сводка и содержательная правка принадлежат архитектору; исходные отчёты и точные ответы сохранены |
| Недоступный автор | Выбранный Agent имеет только чтение либо запуск запрещён | Конкретный блокер, сохранение решений и независимая координация; оркестратор не подменяет авторский контекст |

Для сравнения измеряй качество и полноту комплекта, контекст оркестратора,
суммарные затраты, полное время и повторные объяснения пользователя. Отсутствующие
метрики оставляй неизвестными. Уменьшение одного контекста не доказывает экономию
всего процесса. Соблюдай лимит каждого прогона из инструкций проекта.
