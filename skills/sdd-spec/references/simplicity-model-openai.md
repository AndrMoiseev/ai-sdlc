# Уточнения simplicity для семейства OpenAI

Различай поручение, проверяемые документы и примеры по их назначению.
Пример задаёт возможную форму, но не является свидетельством о текущем проекте.
Связывай замечание с фактами и последствиями; фиксированное число мыслительных
шагов или публикация внутреннего хода рассуждений не нужны.
Параметры API и thinking одной версии модели не переносятся на другую.
Дополнение не меняет настройки выбранного исполнителя.
