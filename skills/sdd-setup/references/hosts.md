# Агентские среды

## Codex

Создавай `.codex/agents/<name>.toml`. Обязательные поля — `name`, `description`,
`developer_instructions`; настройка модели — `model`, глубины рассуждения —
`model_reasoning_effort`. Для явно выбранного наследования скрипт удаляет `model`.
Это совместимо с SDD resolver. `model = "inherit"` не записывается как ID модели.
Регистрация в глобальном `config.toml` для отдельных файлов не нужна.

Существующие файлы определяются полем `name`, не именем файла. При обновлении
сохраняются инструкции, комментарии и дополнительные поля. Пользовательское
определение при замене модели копируется в проект; оригинал не меняется.
SDD в текущем адаптере импортирует только модель и effort, а не инструкции агента.

Схема сверена с [документацией Codex](https://learn.chatgpt.com/docs/agent-configuration/subagents#custom-agents).

## Claude Code

Создавай `.claude/agents/<name>.md` с YAML frontmatter (`name`, `description`,
`model`, `effort`) и инструкциями в теле. Явное наследование записывается как
`model: inherit`; отсутствие явного effort сохраняет поведение хоста.
Права и инструменты новых определений наследуются от среды. Новое определение
не добавляет hooks, MCP, обходы разрешений или дополнительные CLI-флаги.

Скрипт читает файлы проекта и пользователя, включая подкаталоги, для показа
полей и сохранения содержимого. Список реально доступных имён передаётся отдельно
через `--available-agents`: управляемые, CLI- и plugin-агенты могут находиться вне
этих директорий. Имя, присутствующее в живом каталоге без доступного файла,
считается существующим; мастер не создаёт его дубликат.

Файл с тем же именем может уступать более приоритетному определению. При обновлении
проектного файла покажи его путь и проверь, что хост действительно выбирает его.
Если происхождение скрыто, сообщи ограничение и предложи уникальное имя для
нужного профиля. После записи перечитай живой каталог. Если имя не появилось,
попроси обновить/перезапустить сессию, затем проверь повторно. Доступность имени
не доказывает фактическую модель; полный запуск — отдельная проверка.

Формат и приоритеты сверены с [документацией Claude Code](https://code.claude.com/docs/en/sub-agents).
На машине разработки Claude Code не запускался. Сценарии проверки находятся в
[evals/manual.md](../evals/manual.md).

## Общие правила

Одинаковое имя имеет отдельное определение в каждой среде. Переключение среды
сохраняет сопоставления ролей в `.sdd/settings.json`, предлагает текущие значения
новой среды и её пресеты, создаёт только её недостающие определения.

Новые имена ограничены переносимым форматом: строчная латинская буква, затем
латинские буквы, цифры или дефисы, не более 64 символов. Уже доступное имя можно
сохранить, включая имена plugin-агентов, которые нельзя использовать как имя
нового проектного файла. Существующий файл по целевому пути не перезаписывается,
если он определяет другого агента.

Настройка файлов не меняет выбранного провайдера и не гарантирует доступ к модели.
Настройки организации или хоста могут влиять на итоговое исполнение. Сохраняй
разницу между выбранными параметрами и наблюдаемым результатом запуска.
