# SDD Setup

Запускай по явному `$sdd-setup`, `/sdd-setup` или выбору этого скилла пользователем.
Последующие ответы продолжают настройку без повторного вызова.

## Порядок работы

1. Прочитай [условия запуска](references/runtime-setup.md). Определи корень
   проекта и текущую агентскую среду по контексту хоста. Выполни `inspect`
   по [интерфейсу скрипта](references/api.md). Готово, когда получены все восемь
   ролей, текущие значения, пресеты и сведения об агентах.
2. Проведи [диалог настройки](references/dialogue.md). Для отсутствующего
   значения покажи конкретный пресет текущей среды и возможность изменить его;
   для существующего — текущее значение и выбор «оставить / заменить».
   Имена агентов по умолчанию общие для всех сред, модели и effort зависят от
   роли и среды. Наследование предлагается как явный выбор пользователя.
   Готово, когда для каждой роли и каждого выбранного агента записан ответ
   пользователя; согласие на показанную группу значений считается ответом на всю группу.
3. Составь request и выполни `plan`. Скрипт автоматически включит создание
   отсутствующих именованных агентов в родном формате текущей среды.
   Покажи конкретные изменения файлов и сохрани уже принятые решения.
   Если план соответствует ответам, примени его без дополнительного запроса
   разрешения. Если появился новый существенный выбор, уточни только его.
4. Выполни `apply` по [интерфейсу скрипта](references/api.md).
   Проверь список записанных файлов и повторный `inspect`. Для Claude Code
   сверяй обнаружение с живым каталогом по [правилам сред](references/hosts.md).
   Сообщи, какие роли и агенты настроены, и отдели проверку файлов от проверки
   фактического запуска модели.

## На границе записи

- Все восемь ролей имеют явное решение пользователя.
- Модель и effort каждого уникального агента показаны и выбраны.
- Новый вариант имени заново проверен через `inspect --names`.
- План построен из свежего снимка; неизвестные поля проекта сохраняет скрипт.

Записывай настройки только через скрипт. При изменении файлов после обсуждения
повтори чтение и согласуй только изменившиеся значения: устаревший план не
перезаписывает более свежие настройки. Ошибка конфигурации требует исправления
конкретной ошибки, а не замены файла пресетом.

## Область настройки

Скилл управляет `.sdd/settings.json` версии 1 и моделью/effort связанных агентов
на уровне проекта. Остальные поля определений сохраняются. Права доступа,
провайдеры, ключи, MCP и глобальные настройки среды остаются за рамками этого
мастера. Для неизвестного хоста сначала выясни формат и поддерживаемый адаптер;
скрипт поддерживает Codex и Claude Code.

Проверки разработчика и сценарии Claude Code: [evals/manual.md](evals/manual.md).
