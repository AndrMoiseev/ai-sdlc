# SDD

Единый явно вызываемый скилл для исследования, спецификаций, дизайна, независимого ревью и согласованного плана. Рабочие документы сохраняются в `sdd/changes/<change-id>/`; реализация, синхронизация baseline и архивирование находятся за границей процесса.

## Ручное подключение

Скопируйте **весь** каталог `skills/sdd/`, включая скрытые файлы при наличии, `agents/openai.yaml`, flows, references, templates, scripts, pyproject.toml и uv.lock. Для Codex выберите `.agents/skills/sdd/` проекта либо `~/.agents/skills/sdd/`; для Claude Code — `.claude/skills/sdd/` либо `~/.claude/skills/sdd/`. Если целевой каталог уже существует, сравните версии и сохраните собственные изменения до замены. Не перезаписывайте чужие настройки, AGENTS.md, CLAUDE.md или определения агентов. Автоустановщика нет. Пути подключения подтверждены [OpenAI](https://learn.chatgpt.com/docs/build-skills) и [Claude Code](https://code.claude.com/docs/en/skills).

Откройте новую сессию и вызовите `$sdd`/выберите скилл в Codex либо `/sdd` в Claude Code. Например: «`$sdd` исследуй экспорт заказов» или «`/sdd` продолжи order-export». После запуска достаточно обычного диалога. Общая просьба «спланируй изменение» в новой сессии не активирует скилл. Не копируйте только SKILL.md: это потеряет инструкции и политику явного входа.

Понадобятся uv и Python 3.11+; зависимости закреплены локальным lockfile. Команды проверки из любой директории и устранение ошибок — в [runtime-setup](references/runtime-setup.md). OpenSpec не требуется. При отключении пакета сохраните рабочее дерево `sdd/` проекта: в нем документы и история решений.

## Проверенный объем

Техническая сверка 2026-09-29: `codex-cli 0.159.0`, локальная справка exec и официальные контракты skills/subagents. CLI сообщил предупреждения о временном PATH-каталоге, не помешавшие чтению справки. `claude --version` недоступна: Claude Code отсутствует в PATH, адаптер сверен только с [документацией субагентов](https://code.claude.com/docs/en/sub-agents). Минимальная поддерживаемая версия Claude Code не установлена. Инструкции обеих сред поставлены; полная runtime-совместимость не доказана статическими проверками.

Скрипты проверяют структуру и манифесты, но не истинность согласований и не качество рецензента. Контекст и доступность независимых агентов проверяются при запуске. Сквозные испытания на реальном проекте в обеих средах — отдельная работа и здесь не заявляются.

Локальные проверки:

```text
uv run --project skills/sdd --locked python -m pytest skills/sdd/tests
```

[Ручные процедуры](evals/manual.md) разделяют статическую проверку инструкций и фактическое выполнение; [происхождение](references/openspec-origin.md) содержит адаптации OpenSpec и лицензию.
